## Floor Plan Layout Description

The home is a single-story, wood-framed residential building oriented with the
two-car garage at the south end and the main living spaces to the north.

**Entry sequence**: A covered porch leads to the front entry (Door H, 36" wide)
into a foyer. The foyer opens to the central hallway (3'-6" wide) which provides
access to all rooms.

**Living zone** (north/right): Open-concept kitchen, dining, and living area
spanning the full width of the house (~20'). Kitchen includes dishwasher (DW),
refrigerator (REF), and sink. A side exit (Door G, 32" wide) provides secondary
egress.

**Bedroom zone** (north/left):
- Master Bedroom (13'-8" x 12'-0") with walk-in closet and en-suite Master Bath
  accessed via pocket door (C). Master Bath includes W.C., lavatory, and tub.
- Bedroom 2 (12'-2" x 10'-4") with bypass sliding closet doors (I).
- Bedroom 3 (10'-3" x 10'-1") with bypass sliding closet doors (I).

**Shared Bathroom**: Located between Bedrooms 2 and 3, accessed via pocket door (C).
Includes W.C., lavatory, and tub. Linen closet (LN) nearby.

**Garage** (south): 22'-0" x 24'-6" with 16'-0" overhead steel door (J) and
fire-rated self-closing door (E, 36" wide) connecting to the house. Door F (36" wide,
steel) provides exterior side access. Water heater located in upper-left corner.

**Attic access**: 22" x 30" panel in central hallway ceiling.
